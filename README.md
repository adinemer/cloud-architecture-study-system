# Cloud Architecture Study System

A controlled, AI-assisted study system for professional cloud architecture certifications.

## Pilot certification

**AWS Certified Solutions Architect – Professional (SAP-C02)**

The pilot has two equal goals:

1. Pass the certification exam.
2. Improve professional cloud-architecture knowledge, judgment, and hands-on skill.

## Current phase

**System design — no certification study has started yet.**

Before studying, this repository will define and validate:

- the official-provider resource inventory and study sequence;
- which material must be read fully, selectively, AI-extracted, referenced, or used hands-on;
- ChatGPT's roles as coordinator, study partner, instructor, documentation analyst, architecture mentor, and assessor;
- a simple, source-grounded extraction and architectural-enrichment pipeline;
- standardized study artifacts such as summaries, architecture notes, ADRs, decision matrices, flashcards, scenarios, and lab briefs;
- provenance, QA, anti-drift, mastery, and change-control rules;
- a Fedora-friendly toolchain, preferring open source where practical;
- a pilot test that compares pipeline output with manual reading before the workflow is approved.

## Governing principle

Provider material is the source of truth. Versioned specifications in this repository control the process. AI executes within those controls rather than inventing the study process session by session.
